# Ben Thomas

This is my personal website. I write about progress studies, economics, and other topics I'm interested in.

**Site:** [www.benthomas.xyz](https://www.benthomas.xyz)

## Built with Quartz

This site is built with [Quartz](https://quartz.jzhao.xyz/), a set of tools that helps you publish your digital garden and notes as a website for free. Quartz v4 features a from-the-ground rewrite focusing on end-user extensibility and ease-of-use.

Many thanks to [Jacky Zhao](https://github.com/jackyzha0) and all the Quartz contributors for creating and maintaining this wonderful project.
